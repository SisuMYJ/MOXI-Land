# 墨西岛设计方案

Oct 7, 2026 · @Sisu

## 定位和原则

墨西岛是“动森 + Forest”：现实里完成自己定的任务，换来一座一直在自己运转的小岛。岛上的丰富内容是完成任务的动力，但岛本身从不催你。

不能违反的几条：

- **只有正向情绪**：没有失败、没有过期、没有枯萎、没有断签提醒。只靠奖励吸引人。
- **没有义务**：不必要每天解锁、探索或打卡。哪天想要很多治愈，可以一口气解锁很多内容；不想的时候，岛也好好的。
- **居民有自己的小世界**：它们不知道现实里的你在做什么，也不说“慢慢来没关系”这类安慰。它们忙自己的事，岛上一直有故事在发生。
- **打开就有东西看**：不能一分钟就没内容，也不能像排队一样干等。
- **任务是主线**：任务和奖励数量都由你自己定，玩法不往“探索”偏。
- **画面要会动**：萌系手绘，参考动森、猫咪与汤、旅行青蛙，角色要有一点人格化的细节

## 两种货币

星星币管日常，月亮豆管惊喜。两种都只会变多，不会因为没做什么而减少。

| 货币 | 怎么得到 | 用来做什么 |
| --- | --- | --- |
| 星星币 | 完成自己定的任务，奖励数量自己设，可以有建议的不同档位；“做了一点点”也给一点点，什么都没做也给一个 | 商店里的种子、饲料、家具、小礼物，就是种田和饲养的日常开销，商店里可以有惊喜礼盒碎片，集齐可以有一堆星星币，或者月亮币，或者什么小奖励的 |
| 月亮豆 | 比较稀罕：收成卖出、居民回礼 | 解锁新鲜内容：居民之间的故事互动、一段治愈的探索过程、新地块、邀请新居民 |

月亮豆可以攒着，哪天想被治愈一下，就一口气花掉、解锁很多内容。

## 居民

居民像动森里一样各自生活：有家、有日程、有朋友和小脆弱，可以搬进搬出。

**人格化的小细节**（每个居民都有一张设定卡，类似动森）

- 一件随身的小东西和一个小动作：慢熊的睡帽和揉眼睛，团子兔的小背包和蹦跳。
- 爱好、口头禅、怕什么、最喜欢哪类礼物。
- 和谁关系好、和谁偶尔拌嘴，留言板的故事就从这里长出来。

**在岛上做不同的事**

- 每个居民有一天的日程：早上在家、中午去湖边钓鱼、下午串门、晚上坐在山坡上看星星。按你手机的真实时间和天气变化。
- 在岛上会走动，可能正在浇花、看书、打瞌睡、和别的居民聊天。不在外面的就待在家，点房子可以去串门。
- 点它们会说当下在做的事，但每个居民每天只有几句新话，说完就是“在忙”的小动作，不会没完没了。

**搬进搬出**

- 新居民：用月亮豆或邀请碎片邀请，或者偶尔有旅行的动物来访，喜欢就留下。
- 离开只由你决定：好感度高的居民偶尔会说“想去远方看看”，你可以挽留，也可以送它出发。不理它也不会自己走。
- 离开是温柔的：留下一封告别信和一件纪念品，之后还会从旅途中寄明信片回来。
- 岛上房子数量有限（先定 6 间），满了想换人，就是这里的“更换”。

## 小岛动态留言板

留言板每天免费更新 3 到 5 条岛上发生的事，是每天打开的第一个小彩蛋。内容来自居民之间的关系、天气、季节和岛上新解锁的东西，前后还能接上，比如前天吵架、今天和好。

样稿：

- 团子兔和福克狐为“云是不是甜的”吵了一下午，最后决定明天一起爬到树上去尝。
- 慢熊和迷雾猫在湖边坐到了半夜，谁也没说话。第二天两个都说昨晚的月亮很好看。
- 小鹿星灯的花园里长出一颗不认识的芽，全岛都在猜它会开什么花。
- 福克狐把铺子门口的木牌写错了一个字，将错就错，说这样比较可爱。
- 今天下雨，大家都窝在慢熊家，理由是他家的沙发最软。

想知道更多，可以用月亮豆把一条动态“展开”成一段小故事，甚至你也参与进去，比如帮它们和好、陪它们去树上尝云。

## 岛上能做的事

每天打开都有事可做，但哪件都不是必须。星星币的活动是日常，月亮豆的活动是惊喜。

| 活动 | 花什么 | 得到什么 |
| --- | --- | --- |
| 种田和饲养 | 星星币买种子、饲料 | 看它们长大；收成可以卖成少量月亮豆，或者做成礼物（一键饲养，根据拥有的动植物数量扣除星星币，如果不够或者没有点，会暂停生长一天） |
| 送礼 | 星星币买的礼物、自己种的收成解锁碎片 | 好感度、居民回礼、解锁它们和你的小故事 |
| 布置小屋和岛 | 星星币买家具、装饰（不知道要不要有user的小家，会不会浪费时间去装修，可以解锁岛上的装饰或者给居民家的装饰品什么的，或者，购买？） | 居民会去用，比如坐在你放的长椅上晒太阳 |
| 专注陪伴 | 不花钱（发呆时间或者番茄钟专注吧，居民状态要根据不同选项更改，如果发呆就是居民发呆，如果在工作，就是居民在忙碌，如果运动就是居民在锻炼之类的） | 和一个居民一起坐 5、10 或 25 分钟，它在旁边做自己的事，结束给星星币 |
| 特别集市 | 星星币和月亮豆 | 周末或节日开，有平时买不到的种子、家具和来摆摊的旅行动物 |
| 居民故事 | 月亮豆 | 参与居民之间的事：帮吵架的两个和好、陪它们庆生 |
| 治愈的小旅程 | 月亮豆 | 一段可以慢慢看的过程，比如和小鹿一起在湖上放河灯，结束有收藏品 |
| 新地块、新居民 | 月亮豆 | 岛变大，有新的人和事 |

探索只是月亮豆能解锁的一种内容，不做成主线。

## 写台词的规则

居民只讲自己世界里的事，不安慰、不说教、不提现实。

- 不写“不用着急”“慢慢来没关系”“也可以不做”这类话，太刻意会起反效果。
- 居民不知道你现实里做了什么任务。完成任务时的反应是“岛上发生了一件好事”，比如星星落进湖里、大家跑去看，而不是“你真棒”。
- 台词跟着当下在做的事和天气走：钓鱼时说鱼，下雨时说雨。
- 短，一眼读完。每个居民有自己的口头禅和说话节奏。
- 好感度越高，它说的事越私人：一开始聊天气，后来会告诉你它的小秘密。

## 开发顺序

每一步做完都能在手机上打开试玩，由你试完再决定下一步。

1. 新画风的小岛首页：一屏看到整座岛，居民按日程走动、做事、回家。
2. 任务小屋：自己加任务、定奖励，“做了一点点”也算，完成时岛上发生一件好事。
3. 留言板和第一批文本：每个居民的设定卡和 30 句以上台词，100 条以上小岛动态。我原本的设定是千灯铺主人是更人格化一点的，是user的伙伴、好友、伴侣之类的，负责在user不在时候管理小岛，所以留言板每天会在user上线的时候显示小岛动态和千灯铺主人和居民（可能有）给user的留言（治愈暖暖的话，就是想你，或者表达爱意的句子）
4. 商店、种田饲养、送礼和回礼。
5. 月亮豆解锁：居民故事和治愈的小旅程。
6. 搬进搬出、特别集市、更多居民。
7. 做成可以添加到手机主屏幕的网页应用，加存档备份，开始长期自己试用。

待你定的小事：一开始岛上放几个居民（我先按 5 个算），月亮豆要多稀罕（我先按每天正常完成任务大约得 1 颗算）。月亮豆不用刻意控制数量，他的获取方式就比较麻烦，要等饲养成熟，所以就要很多星星币去买饲养动植物还要时间成熟再兑换
